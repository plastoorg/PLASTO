# PLASTO — промостраница для GitHub Pages

Готовый адаптивный лендинг на HTML, CSS и JavaScript, без сборки, фреймворков или серверной части.

## Запуск локально

Откройте `index.html` в браузере либо запустите сервер из этой папки:

```bash
python -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Размещение на GitHub Pages

**Вариант 1 — отдельный репозиторий:** загрузите содержимое папки в корень ветки `main`, затем выберите **Settings → Pages → Deploy from a branch → main / (root)**.

**Вариант 2 — внутри `PLASTO-ORG/PLASTO`:** переместите все файлы этой папки в `docs/` репозитория, затем выберите **Settings → Pages → Deploy from a branch → main /docs**. Если в `docs/` уже есть документация или изображения проекта, не затирайте их — объедините каталоги и проверьте пути.

GitHub Pages публикует сайт по адресу вида `https://plasto-org.github.io/PLASTO/` (для репозитория `PLASTO-ORG/PLASTO`); публикация зависит от настроек Pages.

## Что включено

- Адаптивная мобильная и десктопная версия.
- Оригинальные скриншоты PLASTO в `assets/*.webp`, без перерисовки окон.
- Анимации появления, легкое движение декоративных элементов и поддержка `prefers-reduced-motion`.
- Увеличение скриншотов в галерее с переключением стрелками клавиатуры.
- Меню для мобильных экранов, раздел с ответами на вопросы.
- SEO: `title`, description, Open Graph, JSON-LD SoftwareApplication и alt-тексты.
- Кнопки ведут на реальные GitHub Releases / репозиторий, не требуют внешнего API.

## Как обновлять изображения и тексты

Изображения: `assets/home.webp`, `assets/services.webp`, `assets/speed.webp`, `assets/settings.webp`, `assets/diagnostics.webp`. При замене сохраняйте размеры и имена файлов либо исправьте ссылки в `index.html` и `js/main.js`.

Тексты/ссылки/SEO: `index.html`. Стили: `css/styles.css`. Поведение галереи/меню: `js/main.js`.

Крупный заголовок и некоторые иллюстративные элементы используют шрифты из Google Fonts; без доступа к ним показываются системные шрифты.

## Важные оговорки

PLASTO не является универсальным VPN: локальный DPI-обход не отправляет весь трафик на единый VPN-сервер, однако отдельные функции используют прокси. Скорость и доступность зависят от провайдера, региона и конфигурации. Текущие примеры экранов демонстрационные: показанные задержки, скорости и статусы не являются результатами измерений у посетителя сайта.

Перед публичным запуском проверьте применимую лицензию в репозитории, корректность списка поддерживаемых сервисов и юридические требования своей юрисдикции. Наличие публичного исходного кода само по себе не определяет конкретную лицензию; при необходимости измените формулировку «открытый код» согласно реальным условиям.
