05 / ВОПРОСЫ

Коротко
о главном.

Никакой магии — только понятные инструменты.

Это действительно бесплатно?+

Да. PLASTO распространяется бесплатно. Описание проекта и версии для скачивания доступны в публичном репозитории на GitHub.

PLASTO — это VPN?+

Нет. Для сайтов с DPI-блокировками PLASTO использует локальные способы обхода и не отправляет весь интернет-трафик через единый VPN-сервер. При этом для отдельных сервисов, включая Telegram и некоторые ИИ-платформы, могут использоваться отдельные прокси.

Какая версия Windows нужна?+

Windows 10 или Windows 11, 64-бит. Для некоторых функций зашифрованного DNS нужна Windows 11. Для сетевого драйвера WinDivert потребуются права администратора.

Что делать, если сервис перестал открываться?+

Проверьте статус на главном экране, запустите подбор стратегии или диагностику системы. Доступность зависит от конкретного провайдера и действующих ограничений; работа всех сервисов не гарантируется.

Как удалить PLASTO без следов?+

Сначала выключите обход, при необходимости восстановите hosts и DNS через настройки, затем отключите автозапуск. После завершения приложения удалите .exe и каталог %AppData%\app.plasto.desktop.
